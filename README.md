# 发给 AI 前

免费浏览器本机工具：文字代号替换与当前批次恢复、截图手动实色遮挡。
这是现有项目的静态备用发布源。GitHub Pages已返回公开地址：
https://zhaochengzhi21-cmd.github.io/before-ai-text/

原站：https://before-ai-text-20261017.astutegoby17.chatgpt.site/

## 使用

- 网页首次载入需要联网。输入文字、图片、代号映射仅在本页内存处理，不上传、不持久保存、不调用模型API；不加载统计脚本。
- 电脑可下载 offline-kit.zip，完整解压后打开 index.html；其中两项工具和指南可本机互链。手机实机和本地双击运行仍待验证。
- 保留原文字页完成恢复；刷新、重新检查、重新生成、关闭或浏览器回收可能丢失映射。
- 规则可能漏检。人工遮挡需自行找到全部区域。可以字面恢复，不表示AI理解或回答正确；请先使用虚构示例。
- 分享按钮只复制本备用入口地址，不含输入或映射；官网、徽章和GitHub公开反馈都是外部链接，主动点击才联网，不自动传递材料。

## 已知边界

原站地区自动探针曾返回403或连接错误，不能据此证明国内真人浏览器均不可达。本备用入口同样不保证任何地区可用，需要实际验证。
代码公开供检查不等于独立安全审计。托管服务日志、浏览器扩展、系统剪贴板同步和设备本身不受工具控制。

## 发布维护

静态文件在仓库根目录，保留.nojekyll；无需安装依赖、密钥、后端或自定义Actions工作流。
可在Settings → Pages选择实际默认分支的根目录发布。源文件来自已公开的完整离线包，清单摘要见release-manifest.json。
更新时先重建原工具离线包，再运行本地 build-mirror.py，核对差异后同步；不要上传工作目录、Git历史、运营记录或验证密钥。
